# ApartamentyMilan

A responsive website for an apartment rental business.

## Features

- **Responsiveness:** The site is fully responsive and adapted to various devices.
- **Navigation:** The site includes a responsive navigation menu.
- **Photo Gallery:** The site includes galleries presenting the apartments.
- **Apartment Pages:** Each apartment has its own dedicated page with information and photos.
- **Contact:** Users can find contact information and get in touch with the business.

## Technologies

- React
- SCSS

You can check the website on: https://apartamentmilan.netlify.app
